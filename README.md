# OmniMCP

## Goal

1. **Speed** — хурдан, цөөн алхмаар ажиллах.
2. **Token efficiency** — давтагдах ажлын кодыг `block` болгон дахин ашиглах.
3. **Self-learning** — алдаа, сургамжийг тэмдэглэх; нэмэлт bug-ийг засахаас өмнө **“X алдаа байна. Засах уу?”** гэж товч асуух.

Хурд, token хэмнэхийн тулд хамгаалалт, эрхийн шалгалт, нууцлал болон тестийг сулруулахгүй.
AI-ийн төслийн заавар, хадгалах дүрмүүд: [AGENTS.md](AGENTS.md).

## Боломжууд

- Hyprland desktop-ийг харах, удирдах
- Файл, тохиргоог унших, засах
- Команд ажиллуулах
- OpenCode даалгавар ажиллуулах

## Жишээ хүсэлт

- “Миний desktop дээр ямар цонх нээлттэй байгааг хар.”
- “Төслийн тохиргоог шалгаад өөрчлөлтийг тайлбарла.”
