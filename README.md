# omniMCP

Linux компьютерээ AI туслахаараа удирдаарай.

## Боломжууд

- Hyprland desktop-ийг харах, удирдах
- Файл, тохиргоог унших, засах
- Команд ажиллуулах
- Kanban самбар унших, шинэчлэх
- Canvas файл унших, засах
- OpenCode даалгавар ажиллуулах

## Жишээ хүсэлт

- “Миний desktop дээр ямар цонх нээлттэй байгааг хар.”
- “Энэ Kanban картыг Дууссан багана руу зөө.”
- “Төслийн тохиргоог шалгаад өөрчлөлтийг тайлбарла.”
