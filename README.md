# OmniMCP

# Goal

1. **Speed** — ажлыг хурдан, цөөн алхмаар гүйцэтгэ.
2. **Token efficiency** — давтагдах ажлын кодыг дахин ашиглах `block` болгон хадгалж хэрэглэ (Caveman repo-ийн `block` шиг). Нэг шийдсэн ажлыг дахин эхнээс нь боловсруулахгүй.
3. **Self-learning** — илэрсэн алдаа, сургамжийг тэмдэглэ. Нэмэлт bug-ийг зөвшөөрөлгүй шууд edit/fix хийхгүй; даалгавар дуусахад **“X алдаа байна. Засах уу?”** гэж товч асуу.
