# Self learing OS

**Зорилго:** давтагдах ажлыг бэлэн код/workflow-оор гүйцэтгэж, дахин код бичих, бүтэн эх кодыг контекстэд ачаалахыг багасган token, хугацаа хэмнэх.

## Хэзээ ажиллах

Хэрэглэгч session-оо дууссан гэж үзээд энэ skill-ийг шууд дуудахад ажилла. Автоматаар идэвхжихгүй. Skill-ийг тайлбарлах, засах хүсэлтийг ажиллуулах дуудлага гэж бүү үз.

## Ажиллах урсгал

1. **Дүгнэ:** заасан session, эсвэл энэ ярианы tool call, үр дүнгээс давтагдах ажиллагааг ол. Нэмэлт логийг зөвхөн шаардлагатай үед унш.
2. **Хай:** MCP-ийн одоогийн сан, workflow, helper-ийг эхэлж шалга. Бэлэн шийдлийг олж, саналд тусга; давхар код, tool бүү нэм.
3. **Санал, зөвшөөрөл:** хийх боломжтой ажлыг **1, 2, 3…** гэж дугаарлаж, тус бүрийг **нэг мөрөөр: юу хийх + ямар ашигтай** гэж санал болго. Хэрэглэгч «1, 3» эсвэл «бүгд» гэж зөвшөөрсний дараа сонгосныг л хэрэгжүүл. Зөвшөөрөхөөс өмнө код, MCP-ийн санг бүү өөрчил.
4. **Код болгон хадгал:** дахин ашиглагдах, баримтаар шалгагдсан ажиллагааг параметртэй код/workflow болго. MCP-ийн бүртгэл/executable, эх код, AGENTS.md, одоогийн өөрчлөлтийг шалгаж, сангийн одоогийн бүтэцтэй нэгтгэ. Нэг удаагийн тусгай шийдлийг ерөнхий дүрэм бүү болго.
5. **Олдож, дуудагддаг болго:** санд ID, зориулалт, оролт/гаралт, кодын зам, дуудах жишээг товч бүртгэ. Бүтэн эх кодыг дахин уншихгүйгээр олж, параметрээр ажиллуулж болохыг шалга. Зөвхөн файл хадгалаад бүү дуусга.
6. **Шалга:** тусгаарласан fixture дээр бодитоор дуудаж, үр дүнг батал. MCP интерфэйс өөрчилсөн бол жинхэнэ stdio холболтоор шалга. Ижил ажлын өмнө/дараах tool call, output хэмжээ эсвэл хугацааг харьцуул; хэмжээгүй зүйлийг token хэмнэлт гэж бүү нэрлэ.

## Хүрээ

- Revision/conflict, read-only/dry-run, authentication, background хамгаалалт болон хэрэглэгчийн өөрчлөлтийг хадгал.
- Нууц мэдээлэл, бүтэн session-ийг санд бүү хуул. Хэрэгтэй давтагдах ажиллагааг л нэм; тохирох зүйлгүй бол хэлээд дуусга.
- Холбоогүй provider, model training, суурь prompt, memory болон энэ skill-ийг бүү өөрчил. Watcher, давтамжтай background ажил бүү үүсгэ.

## Тайлан

Юуг дахин ашигласан/нэмсэн, хаана хадгалсан, яаж дуудах, шалгалт, хэмжсэн ашиг болон үлдсэн хязгаарлалтыг товч монголоор хэл. Эх код, суулгасан хувилбар, одоогийн MCP session-д орсон өөрчлөлтийг ялгаж тайлагна.
